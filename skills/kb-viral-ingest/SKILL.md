# `kb-viral-ingest` — 爆款文案科学拆解与跨篇归因入库规范

> 核心原则：**拒绝“情绪价值/干货满满/戳中痛点”这类事后诸葛亮式的空泛标签。先剥离非文本光环，再以「3–5 条硬上限 + 1 条第一胜负手 + 反事实检验 + 负样本最小差异对照」做可验证归因，最终沉淀为去题材化的可复用骨架。**

## 适用场景与隔离边界

- **何时调用**：
  1. **正样本（爆款）**：高赞文章、爆款短视频脚本、高转化落地页文案、爆款标题/钩子合集。
  2. **负样本对照（Minimal Pair）**：同一赛道或同一账号下，题材相近但点赞/完播/收藏明显偏低的平庸或翻车文案（强烈建议每拆 3–5 篇爆款，顺手录入 1–2 篇同主题负样本，从根源消除幸存者偏差）。
- **同库逻辑隔离**：所有拆解页统一写入当前知识库，必须标注 `domain: "viral-copywriting"` 与 `visibility: private`，创作模式（`--mode creator`）下可与通用认知页跨界组合，学员问答（`--mode student`）下完全隔离。

## 一、爆款归因的五大科学底层框架（分指标拆解，严禁混为一谈）

**完播、点赞、收藏、转发、评论**是 5 种截然不同的大脑决策。拆解时必须按指标对号入座，优先从以下经过实证验证的经典理论中提取标准 `mechanisms` 名称：

| 目标指标 | 核心科学机制（标准 `mechanisms` 词） | 经典理论与原著依据 | 可观测文本特征 |
| :--- | :--- | :--- | :--- |
| **开篇停驻 / 截停率** | `信息缺口理论`、`期望违背`、`损失厌恶` | George Loewenstein《好奇心心理学》；Chip & Dan Heath《粘住》；Daniel Kahneman《思考，快与慢》（前景理论/System 1-2） | 先给熟悉锚点再开具体可闭合缺口；打破常识图式触发预测误差；点出正在发生的隐性损失/踩坑成本 |
| **中段留存 / 完播率** | `蔡格尼克效应`、`认知流畅度`、`双重编码具象化`、`认知负荷控制` | Bluma Zeigarnik（未完成悬念张力）；Robert McKee《故事》；Allan Paivio 双重编码理论；John Sweller 认知负荷理论 | 大悬念套小悬念（开放回路节拍）；短句/清晰数字框架降低加工阻力；用感官画面与具象案例替代抽象形容词 |
| **点赞 / 情绪共鸣** | `高唤醒情绪`、`社会镜像共鸣`、`替受众发声` | Jonah Berger《疯传》（高唤醒：敬畏/兴奋/幽默/愤怒/焦虑 vs 低唤醒：悲伤/满足）；Robert Cialdini《影响力》（相似性/喜好） | 触发高唤醒情绪而非平淡抒情；精准说出受众“心里一直有感但自己表达不出来”的隐秘体验或委屈 |
| **收藏 / 转发率** | `社交货币`、`认知卸载`、`实用价值`、`场景诱因绑定` | Jonah Berger《疯传》（STEPPS 模型）；Evan Risko 认知卸载理论 | **收藏**靠“未来用得到+现在记不住”的清单/模板/阈值；**转发**靠帮读者向他人展示品味/立场/内幕（社交货币）或绑定高频日常场景 |
| **评论 / 行动转化** | `福格行为模型`、`先发影响力`、`社会认同`、`亚里士多德修辞三要素` | BJ Fogg《福格行为模型》（$B=MAP$）；Robert Cialdini《影响力》《先发影响力》；Aristotle《修辞学》（Ethos/Pathos/Logos） | 极低门槛互动提示（二选一/填空/轻度争议留白）；先立亲历可信度（Ethos）再唤情绪（Pathos）再给证据（Logos） |

> **禁词红线**：严禁单独使用“有情绪价值”“戳中痛点”“干货很多”“共鸣感强”“节奏很好”作为归因结论——必须翻译为上表中的具体科学机制并指明对应的原文证据句。

## 二、标准入库与科学拆解动作链（严格按序执行）

### 0. 入库前零污染清洗与归档
先剔除平台 UI 噪声、水印、时间戳与乱码断行，保留原文完整文本与**可验证的表现数据**（平台、发布时间、点赞/收藏/评论/转发/完播率等，未知则标 `未知`，严禁编造），再执行 `kb scan --json` 或 `kb add --text ... --json` 归档进 `raw/`，并开启事务 `kb compile-begin --json`。

### 1. 前置「非文本混淆变量剥离」（防把账号光环误判为文案技巧）
在动笔分析句子之前，必须先在拆解卡顶部做一次**混淆变量剥离评估**：
- **账号信任背书**（大 V 光环 / 既有粉丝基本盘：高 / 中 / 低 / 未知）
- **视觉/口播/剪辑表现力**（人设镜头感、节奏剪辑、BGM 贡献：高 / 中 / 低 / 未知）
- **时效热点/平台红利**（是否借势热搜/突发事件：是 / 否 / 未知）
- **话题自带争议性**（是否天然踩在高频争论议题上：高 / 中 / 低）
- **纯文本可迁移贡献估评**：明确指出“剥离上述非文本因素后，有哪些结构/句式换到普通素人账号上依然成立”。**只有剥离后仍成立的纯文本变量，才允许提炼进 `concepts/` 技法库。**

### 2. 跨篇前置检索与最小差异对照（超越单篇记忆）
在写拆解页前，**必须先检索库内已有爆款与负样本**：
```bash
kb query "<核心机制词或题材词>" --type case --json
kb query "<核心机制词>" --type concept --json
```
- **正样本对照**：找出 1–3 篇结构相似或同题材的旧爆款，比对异同。
- **负样本最小差异对照（Minimal Pair）**：若本次录入的是**负样本对照**（低赞/翻车文案），或在库中找到了同题材的负样本，必须重点比对“**题材相似、但结果悬殊的 1–2 个关键最小差异变量**”（例如：同样讲省钱，爆款用具体损失金额开篇，负样本用抽象道理开篇），并用 `relations: type: "contrasts"` 显式配对。

### 3. 严控数量上限的四元组因果归因（防 AI 硬凑理论）
- **硬性上限**：单篇文案**最多只提炼 3–5 条核心因果归因**（按贡献度从高到低排序，宁缺毋滥，严禁硬套十几个理论注水）。
- **唯一第一胜负手**：必须明确标出 **1 条「第一胜负手（Primary Driver）」**——即最核心的决定性变量。
- **固定四元组 + 反事实检验**：
  1. **目标指标**：明确归因对象（截停 / 完播 / 点赞 / 收藏 / 转发 / 评论）。
  2. **原文证据**：逐字引用触发该机制的原文句子或结构段落。
  3. **科学机制**：映射到上表中的标准科学理论，解释大脑为何会产生该反应。
  4. **反事实检验（Counterfactual Check）**：回答 *“如果删掉这句或改写为平铺直叙，哪项指标会最先下滑、为什么？”* 答不出明确差异则直接剔除。
- **证据置信度分级**：单篇爆款归因默认为 `status: "candidate"`（结构假说）；经库内 **$\ge 2$ 篇独立正/负样本交叉印证**或**本人实战复刻验证**后，升级为 `status: "confirmed"`。

### 4. 强制产出「去题材填空骨架 + 失效边界」（打通复用最后一公里）
每篇爆款拆解案例（`cases/`）或通用技法页（`concepts/`）末尾，必须附一段**去题材化的填空骨架**：
- **去题材填空骨架**：把具体行业词挖空，只保留可迁移的逻辑槽位（例如：`[大众习以为常的做法] → [用具体数字戳破隐性损失] → [抛出 1 个反常识底层机制] → [给出 1 个低门槛具象动作] → [二选一低门槛互动提问]`）。
- **失效边界（何时不能抄）**：明确写出该骨架在哪些前提下会失效或反噬（例如：“无信任背书的新号直接套用强权威断言会触发防御心理”“纯情绪宣泄型骨架直接套用到高客单专业科普会拉低收藏率”）。

### 5. 精准落入 5 大原子页与标准 Frontmatter
- **`sources/`**：爆款（或负样本）原文精读卡（数据基准 + 非文本混淆变量评估 + 整篇骨架）。
- **`cases/`**：单篇拆解案例（3–5 条因果归因 + 第一胜负手 + 同类/负样本横向对照 + 去题材填空骨架与失效边界）。
- **`concepts/`**：**优先增量融合**到已有通用技法页，不重复造轮子。
- **`evidences/`**：按题材聚合的高转化原句钩子库 & 实测数据对照（附 `raw/` 溯源）。
- **`insights/`**：仅在跨篇对比（尤其是正负样本最小差异对照）产生新规律时沉淀。

```yaml
---
type: case                            # source | concept | case | evidence | insight
title: "自然流畅的中文标题"
summary: "不超过 50 字的精炼归因摘要（注明第一胜负手）"
status: stable                        # draft | stable | deprecated
tags: [爆款拆解, 短视频脚本]             # 若为低赞对照样本，追加 负样本对照
aliases: ["可搜口语词", "核心结构别名"]
domain: "viral-copywriting"
visibility: private
reading_status: read
experience_type: others               # 他人样本标 others；自己实战跑出的样本标 firsthand
origin: mixed
layers: [L1, L2]                      # L1 文本现象 / L2 心理与传播机制 / L3 跨篇策略规律
mechanisms: ["信息缺口理论", "损失厌恶", "社交货币"]
relations:
  - target: "../cases/同题材对照案例.md"
    type: "contrasts"                 # analogizes（结构同构）| contrasts（正负样本/同题异果对照）| applies_to（应用某技法）
    status: "candidate"               # 单篇推测标 candidate；多篇交叉印证或实战复刻后改 confirmed
    layer: "L2"
    reason: "同题材对比：爆款在前 10 秒用具体隐性损失锚点触发损失厌恶，负样本仅做抽象说教，完播与赞藏差距显著"
generated:
  by: "agent:kb-viral-ingest"
  at: "YYYY-MM-DD"
verified: []
sources:
  - id: s1
    ref: "../../raw/YYYY-MM-DD-文件名.md"
---
```

### 6. 安全校验与事务提交
- 严禁修改 `<!-- human:start -->` 区块、严禁修改 `verified` 页面既有正文、禁止 `[[wikilinks]]`。
- 执行 `kb compile-commit --session <session_id> --note "爆款科学拆解：<标题>" --json` 完成全量校验、索引重建与 Git 快照提交。
- 若返回 `evolution.evolve_recommended == true`，可按需调用 `skills/kb-evolve/SKILL.md` 检查爆款归因机制词与召回权重是否需要增量微调。
